## A1

A1 was the first version of the site. I made Lab 1 with the HTML examples, like headings, lists, tables, images, forms, and links, and I put my name and GitHub on the Labs page. Kambaz was mostly static screens. You can sign in, see course cards on the dashboard, open a course, and click through Home, Modules, and Assignments. The assignment editor was just a form and it did not load real assignment data yet.

## A3

A3 adds Lab 3 and hooks Kambaz up to the reference data. Lab 3 is the JavaScript chapter, so the page goes through variables, arrays, functions, classes, the pathname, the server file list, the add pages, and the todo list. The labs menu highlights whichever lab I am on.

For Kambaz I downloaded the courses, modules, assignments, users, and enrollments json and the screens read from that. Modules and Assignments filter by the course in the url, the editor fills in the title, description, points, and dates for the assignment I opened, and the people table only lists users enrolled in that course. Home, Modules, and the assignments list still use the last part of the url. The side menus highlight the screen I am actually on.

The A3 With AI parts I added on Kambaz are the ones from the chapter checklist. History is on the main sidebar. Every course has a term of Spring 2023. The dashboard also shows RS104 Organic Chemistry. The course heading shows the course id in parentheses. The course menu has Announcements. The people table heading says People instead of Table. Nozzle Design is a lesson under Fuel and Combustion on RS101. RS102 assignments also list A4, which is A204. The editor shows Assignment id, like Assignment id: A101. Thor Odinson is also on the RS102 people table.
